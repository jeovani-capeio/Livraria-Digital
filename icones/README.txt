# LivroVivo — Ícones SVG locais

Pacote de ícones para o projeto do site de livros.

## Características
- SVG puro
- Sem JavaScript
- Sem CDN
- Sem Internet
- `currentColor`: a cor pode ser controlada pelo CSS
- 24x24 por padrão
- Traço de 1.8px e cantos arredondados

## Uso

```html
<img src="icons/search.svg" alt="Pesquisar">
```

Para controlar a cor diretamente via CSS, é melhor inserir o SVG inline no HTML. Se usar `<img>`, a cor interna `currentColor` depende do contexto e normalmente não acompanha o `color` do elemento.
